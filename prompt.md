## Pipeline Breakdown## 1. The Passive Health Connect Pipeline

- Purpose: Establishes a 24-hour moving baseline context without impacting the peripheral device's battery life.
- Mechanism: The background system executes a passive timer polling check once every 60 seconds against the local Android database.
- Data Aggregation: The code fetches all discrete biometric records written by the native health ecosystem over the prior 24 hours. It flattens the nested intraday arrays (sample arrays) generated by modern Health Connect schemas and calculates a mathematical mean.

## 2. The Active BLE Broadcast Pipeline

- Purpose: Bypasses local operating system write schedules to achieve live telemetry updates at sub-second frequencies during workouts.
- Mechanism: Leverages native OS Bluetooth adapters via the central BleManager interface. It initiates scans filtered specifically for the official Bluetooth SIG Heart Rate Service UUID (0x180D).
- Parsing Specifications: Heart Rate Measurement packets arriving over BLE utilize custom binary packaging.
- Byte 0 (Flags): The system evaluates bit index 0. A configuration state value of 0 denotes standard 8-bit tracking (values limit to under 255 BPM). A state value of 1 signifies an advanced 16-bit tracking packet.
  - Byte 1+ (Payload): Depending on the flag assessment, the application dynamically shifts its stream decoding operations using either native Little-Endian 16-bit array mapping or straight 8-bit parsing to extract clean numeric integer streams.

## State and Resource Lifecycle Controls

- Mutual Exclusion Rules: When an active Bluetooth connection initiates, the target device establishes an explicit link with your software process. The standard Fitbit application background processes will defer synchronization tasks gracefully until you terminate your session.
- Garbage Collection Protocol: The integration uses references to track long-running hardware tasks like active scanners, connection states, and polling timers. When a user changes views or closes the app, the code safely releases these resources to prevent memory leaks or continuous background battery drain.
